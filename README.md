# VoltRelay Energy – Battery Swapping Network Analytics

## Project Overview

This project analyzes the operational performance of VoltRelay Energy,
a battery-swapping network operating across six Indian cities.

The analysis uses approximately 3.9 million swap attempts recorded
between January 2024 and June 2025.

The objective is to identify service failures, station-level issues,
city-level performance differences, charger-generation patterns and
rider retention trends.

## Business Objectives

- Measure overall network performance
- Identify major service failure reasons
- Compare performance across cities and stations
- Analyze charger-generation performance
- Identify peak failure periods
- Study rider retention and churn patterns
- Generate actionable operational recommendations

## Key Results

- Total swap attempts: 3,877,013
- Completed swaps: 3,645,809
- Overall failure rate: 5.96%
- Battery availability + queue abandonment: 87.77% of failures
- Highest city failure rate: Jaipur – 7.85%
- Gen1 charger failure rate: 7.23%
- Gen2/Gen3 charger failure rate: 4.84%
- Highest hourly failure rate: 21:00 – 6.65%
- Analytical rider churn rate: 39.60%

## Important Note

The dataset is synthetic.

The analysis identifies associations in the available data and does
not establish causal relationships.

The churn metric is an analytical definition based on rider inactivity
and is not an official churn label.
